ЖД отдел — рынок фитинговых платформ

1. Выполните supabase_rail_dashboard_schema.sql один раз в Supabase SQL Editor.
2. Создайте пользователей в Supabase Authentication -> Users.
3. Загрузите index.html и .nojekyll в корень GitHub-репозитория.
4. Включите GitHub Pages: Settings -> Pages -> Deploy from a branch -> main / root.
5. Откройте опубликованный сайт и войдите под учетной записью сотрудника.

Supabase Project URL и publishable key уже встроены в index.html.
Secret/service_role ключи в файл не добавлены и не требуются.
